# AI Providers Integration

**Swiss Travel Planner** supports any AI API compatible with the standard OpenAI `/v1/chat/completions` REST format.

---

## Supported AI Providers

| Provider | Recommended Model | API Endpoint URL | Key Required |
| :--- | :--- | :--- | :--- |
| **OpenRouter** | `google/gemini-2.5-flash` | `https://openrouter.ai/api/v1/chat/completions` | Yes |
| **OpenAI** | `gpt-4o-mini` | `https://api.openai.com/v1/chat/completions` | Yes |
| **Groq** | `llama-3.3-70b-versatile` | `https://api.groq.com/openai/v1/chat/completions` | Yes |
| **MiniMax** | `MiniMax-M2.7` | `https://api.minimax.io/v1/chat/completions` | Yes |
| **Ollama (Local)** | `llama3.2` | `http://localhost:11434/v1/chat/completions` | No |
| **Custom Endpoint**| Any compatible model | User defined URL | Optional |

---

## Setup Methods

### Method 1: Interactive Browser UI Modal (Client-Side)

1. Click **AI Settings** (⚙️) in the top header.
2. Select your provider preset from the dropdown menu.
3. Input your API key.
4. Click **Test Connection** (⚡) to verify credentials.
5. Click **Save Settings** to persist config to browser `localStorage`.

---

### Method 2: Global Preset in `config.js`

To specify a provider globally for all site visitors, edit `config.js`:

```javascript
ai: {
  defaultProvider: "groq",
  providers: {
    groq: {
      name: "Groq",
      endpoint: "https://api.groq.com/openai/v1/chat/completions",
      model: "llama-3.3-70b-versatile",
      requiresApiKey: true
    }
  }
}
```

---

### Method 3: Ollama Local AI Setup (100% Free & Offline)

You can run local AI models completely free using [Ollama](https://ollama.com/):

1. Install Ollama and pull your desired model:
   ```bash
   ollama run llama3.2
   ```
2. Open **AI Settings** in Swiss Travel Planner.
3. Select **Ollama (Local)**.
4. Endpoint: `http://localhost:11434/v1/chat/completions`
5. Model: `llama3.2`
6. API Key: *(Leave blank)*
7. Click **Test Connection** and **Save Settings**.

---

## Response Parsing & Robustness

The engine handles multiple model output formats gracefully:

- **Strict JSON Object**: Native JSON output via `response_format: { type: 'json_object' }`.
- **Markdown Codeblocks**: Strips ```json ... ``` formatting.
- **Reasoning Tags**: Filters out `<think>...</think>` tags generated by reasoning models (such as DeepSeek-R1 or Qwen-QwQ).
- **Graceful Fallback**: Automatically reverts to internal database if network or API errors occur.
